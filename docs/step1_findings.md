## 一、设计定案与具体化(文档留白处的选择,均可复议)

**角色定案(C4,Xinyue 裁决)**:被扫描/被推断方 = opponent(周车画像),
ego 为观测者/决策者、画像固定(= 两步法辨识中"对手条件选择概率已知"
假设的数值对应)。不做对称扫描:对称扫描回答的是群体比较静态问题
(Stage 5),且扫描点变动时双方响应同变,等价脊线会混入"对手也变了"
的效应,与两步法辨识定理对不上号。ego 固定值三组
(baseline / safety_biased / low_precision),主实验只用 baseline,
另两组做 15³ 粗网格脊线拓扑鲁棒性检查。

**可观测量口径(C5)**:观测等价用 opponent 的均衡选择概率
q\* = P[opp=yield] 定义;p\* 不进判据——ego 画像固定时 p\* = Φ_e(q\*)
是 q\* 的确定函数,不含额外信息。等价:各情境 |Δq\*| < tol(=0.01)。

**观测预算口径(C6)**:单情境版全部 N 次观测来自 balanced;多情境版
**同一总预算** N 均分三情境(10→4/3/3)——固定预算才能干净度量
"情境多样性本身值多少数据"。真参数复用 equivalence 三参考点
(好/中/坏辨识条件对照;原待裁决事项③,已按默认执行并经确认)。

**C1 具体化**:
- 离散度定义:某玩家某分量在全部 2×2=4 个动作组合上的总体标准差 (ddof=0)。
- 情境缩放方案:保均值(只缩放对均值的偏差)+ 保两分量离散度几何均值
  (σ_s·σ_e = const),对两个玩家各自独立施加同一 c。
  含义:c 只改变"哪个分量的动作间差异主导",不改变整体 payoff 尺度与均值。
- payoff 基础数值为占位设定(merge/hold 为双方安全冲突点,wait/hold 为
  opponent 舒适点),全部在 config 中,可随时调整。

## 二、结构性理论结果(C2,推导层面成立,后被数值精确证实)

二动作 component-probit 解析式:P(a₁) = Φ(Σ_k w_k Δū_k / τ),
其中 **τ² = 2(1/κ_s + 1/κ_e)**。噪声与 payoff 无交互,因此:

1. (κ_s, κ_e) 只通过聚合量 1/κ_s + 1/κ_e 进入选择概率——在任何对手策略、
   任何情境 c 下,聚合量相同的 κ 组合产生逐位相同的选择概率
   (`test_kappa_enters_only_through_aggregate`,解析路径 rtol=1e-12)。
2. 推论:(κ_s, κ_e) 平面的等价脊线必然是精确双曲线 1/κ_s+1/κ_e=const,
   且不随情境数收缩;情境变异真正能分离的是 (w_s, τ)
   (c 改变 Δū_k 的相对大小,不改变 τ)。
3. 该不可辨识对任意动作数均成立(噪声聚合与动作数无关)。

**结论改述**:separable 噪声下,Step 1 的可辨识对象是 **(w_s, τ)**,
κ 分量级分离需要模型层修改(见待裁决①)。

## 三、数值发现

### C5 核心发现(50³ 网格,tol=0.01,seed=42)

**发现 1 — κ 双曲线简并被精确证实。** (κ_s, κ_e) 平面上三个情境的
等价脊线是同一条沿理论双曲线的带,三情境交集与单情境集合基本重合、
不收缩(连通分量数恒为 1;`test_kappa_hyperbola_equivalence_in_every_situation`
验证聚合量相同 ⇒ |Δq\*| < 0.1·tol,对每个 w_s、每个情境)。

**发现 2 — 情境变异确实分离 (w_s, τ)。** (w_s, κ_s) 平面单情境是宽补偿带,
三个情境带方向不同(balanced 下倾、safety_dominant 更陡、
efficiency_dominant 反向),交集显著收缩。体积占比(1→2→3 情境):

| 参考点 | 1 情境 | 2 情境 | 3 情境 | 收缩 |
|---|---|---|---|---|
| cautious_low_prec | 0.0555 | 0.0177 | 0.0038 | ~15× |
| cautious_high_prec | 0.0285 | 0.0003 | 0.0003 | ~92×(第 2 情境已饱和)|
| efficient_mid | 0.0184 | 0.0098 | 0.0030 | ~6× |

3 情境后的剩余体积/直径主要就是发现 1 的双曲线简并方向。

**发现 3 — 辨识强度取决于参考点距行为无差异点的远近。**
q\* = Φ(DV/τ) 中 τ 只通过 DV/τ 进入:若某画像在所有情境下 DV≈0
(q\*≈0.5),τ 沿任何方向变动都几乎不动 q\*,弱可辨识。数值对照:
cautious_low_prec 的 q\* 三情境 (0.53, 0.55, 0.47) 全贴 0.5,3 情境后
直径仍 0.78;cautious_high_prec 的 q\* (0.60, 0.70, 0.41) 跨情境拉开,
3 情境后直径 0.33(基本只剩双曲线弧)。
含义:**有效的情境变异 = 能把 opponent 的 q\* 以不同方式推离 0.5 的情境**
——对"什么情境变异能分离参数"的定量回答,值得进论文正文。

### C6 观察(20 replicates,95% 似然比集合,seed=42)

体积中位数(N=10 → 1000):

| 真参数 | single | multi |
|---|---|---|
| cautious_high_prec | 0.937→0.137 | 0.899→**0.006**(23× 优势)|
| efficient_mid | 0.940→0.074 | 0.884→0.055(温和优势)|
| cautious_low_prec | 0.937→0.245 | 0.905→0.204(几乎无差别)|

1. **C5 渐近结构在有限数据下重现**:好辨识条件下多情境优势随 N 急剧
   放大;直径上单情境 N=1000 仍卡 1.0(完整补偿曲线未被切断),
   多情境降到 0.42。
2. **优势存在 N 门槛**(约 N≈100–300 交叉):小 N 时 Binomial 噪声淹没
   情境间 q\* 差异,分散预算无收益。对实际数据采集的直接含义:
   短观测窗口下堆情境数不如堆单情境样本。
3. **无差异点弱辨识在有限数据下同样成立**:cautious_low_prec 两版曲线
   几乎重合、直径恒 1.0——q\*≈0.5 时情境变异与数据量都救不了 τ。

truth_coverage(真参数落入 95% 集合的频率)全程 ≈ 1,似然比集合校准
合理(网格化真参数,略保守)。

### C3 动力学观察(极端 κ 摸底)

- κ=10⁶、w=(0.5,0.5):多起点恰好找到两个稳定 QRE,贴近加权博弈的两个
  纯 Nash (merge,yield) 与 (wait,hold)(误差 <10⁻³),协调博弈结构与手算一致。
- 13 个起点中 3 个(含均匀起点)落入 (merge,hold)↔(wait,yield) 反协调
  2-周期振荡不收敛:内部混合 QRE 在极端 κ 下不稳定,damping=0.5 拉不进
  吸引盆。多起点机制正确排除未收敛 run。备选处置(未收敛点降 damping
  重试)未引入——C4 扫描范围内未出现该现象,暂无必要。
- 唯一性:w=0.5、对称 κ∈[0.5,32] 均衡唯一;κ=10⁻⁶ 时唯一均衡为均匀
  策略(偏差 ~10⁻⁵)。中等 κ 收敛 30–150 步,自洽性残差 ~10⁻¹¹。
- **C4 扫描范围内(w_s∈[0,1], κ∈[0.1,30] log 轴,ego κ=3):全部格点
  收敛、无回退、无多重均衡**——规范均衡选择无歧义,C5 无需处理
  均衡选择分支。

## 六、Step 1 结论速写(供论文/下一步讨论)

- separable component-probit 下,可辨识对象是 (w_s, τ),τ²=2Σ1/κ_k;
  κ 分量级分离需要模型层修改(payoff 依赖噪声),为待裁决扩展。
- 情境变异分离 (w_s, τ) 的机制与条件已定量:有效情境 = 使 opponent 的
  q\* 以不同方式偏离 0.5;参考画像越贴近行为无差异点,τ 越弱可辨识。
- 有限数据:多情境优势有 N 门槛(≈100–300);好条件下 N=1000 时体积
  优势 ~23×。短观测窗口应优先堆单情境样本,长观测窗口才值得铺情境多样性。
